# Avatar Pipeline

Unified semantic avatar reconstruction pipeline.

## Features

- Background removal
- Human semantic parsing
- Body reconstruction
- High-detail face reconstruction
- Mesh fusion
- Canonical retopology
- UV unwrapping
- Texture baking
- Rigging
- GLB export

## Goals

- No subprocesses
- No Blender requirement
- No external project wrappers
- Pure Python orchestration
- Deterministic pipeline architecture
